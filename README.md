**RinsTrap** is a lightweight bootstrapper for Roblox. It provides a clean, modern UI for managing your Roblox installation with features like custom death sounds, GUI recolors, Discord Rich Presence integration, and more.

### Features

- **Fast launch** — Gets you into Roblox quickly
- **Custom death sounds** — Replace the default sound with your own
- **GUI recolors** — Apply custom color themes to the Roblox interface
- **Discord Rich Presence** — Show what game you're playing on your Discord profile
- **Activity tracking** — View statistics about your play sessions
- **Custom FastFlags** — Tweak Roblox engine settings with a built-in editor
- **Shortcut creation** — Create desktop and Start Menu shortcuts with custom icons

### Download

Download the latest release from the [Releases page](https://github.com/0wwzr/RinsTrap/releases/latest).

### Building

Requires the .NET 6 SDK.

```
dotnet build -nologo
```
