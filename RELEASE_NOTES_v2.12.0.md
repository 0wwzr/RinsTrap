# RinsTrap v2.12.0

## New Features

### Roblox GUI Recolors (Mods)
- New **GUI color preset** picker on the Mods page
- 6 themes included: **Purple, Rainbow, Synthwave, Yellow, Deep Blue, Red**
- Retextures the Roblox interface — applied on your next Roblox launch
- Switching presets or going back to *None* cleanly removes old files

### Statistics Overhaul
- Brand-new stat cards: **Games played**, **Average session**, **Active days**, and **Most played** game
- The Last 7 Days list is now a proper **bar chart**, scaled to your busiest day
- **Top Games** now shows real **game logos and names** (fetched from Roblox)
- Click any game card to open its Roblox game page

### Discord Rich Presence
- Your status now shows: ***Playing \<game\> with RinsTrap***

### FastFlags
- New **Unlimited frame rate** preset — adds the Maximum Frame Rate setting to the in-game menu, removes the 240 FPS clamp, and uncaps your FPS
- Completely redesigned preset library: icon card grid, category headers with counts, applied badges, and smarter Apply/Remove buttons

### Updates & Changelog
- RinsTrap now checks for updates from its own repository (**0wwzr/RinsTrap**) and auto-updates itself
- New **"What's new"** window that automatically shows the changelog after an update
- Manual "What's new" button under Settings → RinsTrap
- Option to disable the automatic changelog popup

## Changes & Fixes
- Removed all external links, the About page, and help buttons across the app
- Exception dialog no longer links out; keeps the local log file shortcut
- Various text cleanups
