# RinsTrap v2.13.0

## New Features

### Mods
- **Custom GUI recolor import** — new *"Add your own"* button next to the GUI color dropdown. Pick any folder containing a `content` and/or `ExtraContent` folder and it becomes a **Custom** entry in the preset list (wrapper folders are auto-detected)
- **Custom death sound** — pick any OGG, MP3 or WAV file from your computer to use as your death sound. Nothing is downloaded or uploaded, it all stays on your PC

### Integrations
- New option: **"Close Roblox completely when closed"** — when enabled, closing the Roblox window also closes any Roblox processes left running in the background

## Changes & Fixes
- Removed the built-in FastFlag preset library — the **FastFlag editor is now front-and-center** at the top of the FastFlags page for adding your own flags
- MSAA, texture quality and display scaling presets remain unchanged
