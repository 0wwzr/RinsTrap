# Statistics Tab - Feature Requests & Improvements

## Core Tracking Improvements

### 1. Accurate Game-Only Playtime Tracking
- **Track ONLY when in actual Roblox games** (not in menus, home screen, avatar editor, etc.)
- Detect game join/leave events via Roblox process monitoring
- Track per-game playtime with place ID and universe ID
- Ignore time spent in Roblox Studio, home page, avatar shop, settings, etc.
- Use Roblox process command line args or memory scanning to detect game state

### 2. Roblox App Process Tracking
- Track `RobloxPlayerBeta.exe` process lifecycle
- Monitor CPU/memory usage per session
- Detect crashes vs clean exits
- Track multiple concurrent Roblox instances separately

### 3. Granular Time Tracking
- **Per-second resolution** for active gameplay
- **Pause tracking** when: minimized, alt-tabbed, game paused, AFK > 30s
- **Resume tracking** on focus restore
- **Idle detection** (no input > 60s = pause)

- Today / Yesterday / This Week / Last Week / This Month / Last Month / This Year / Last Year / All Time

## Technical Implementation

### 1. Data Storage
- **SQLite database** for local stats (better than JSON for queries)
- **Partitioned by month** for performance
- **Indexed by** date, game ID, session ID
- **Auto-cleanup** option (keep last N years)

### 2. Performance
- **Lazy loading** for charts (virtual scrolling)
- **Background aggregation** (don't block UI)
- **Cached aggregations** (refresh on new data only)
- **Pagination** for large datasets (sessions list)

### 3. Privacy & Sync
- **Local-only** by default (no cloud)
- **Optional encrypted backup** to user's cloud
- **Export/Import** for migration
- **GDPR-compliant** delete all data option
